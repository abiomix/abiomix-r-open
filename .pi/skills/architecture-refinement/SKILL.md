Observe → conjecture → probe → confront surprises → revise → consolidate. Separate binding owner commitments from current observations and implementation hypotheses. Use an independent oracle and small native-runtime experiment; do not weaken a contract to pass a generated test. Preserve justified code and user data. Code organization, domain names, nearby tests and provenance carry the working theory; more documents or generated code are not progress by themselves.

Checkpoint meaningful discoveries, uncertainty and handoffs, not routine mechanical edits. Return the scoped model, evidence, risks, unresolved question and next bounded action. Distinguish ready to investigate, implement and ship. Documentation does not certify owner understanding. Publication, merging, production changes and destructive actions require the task's authorization.
